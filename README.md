# 📄 Sheet Unlocker — Документация

## 📦 Описание

**Sheet Unlocker** — это расширение для браузера, которое позволяет открывать Google Sheets в режиме `htmlview`, где текст становится доступным для копирования.

Обычно Google Sheets ограничивает копирование в стандартном интерфейсе — это расширение обходит это ограничение, открывая альтернативное представление страницы.

---

## ⚙️ Установка

Расширение устанавливается вручную из `.crx` файла.

### Способ установки:

1. Откройте страницу расширений браузера:
    
    ```
    chrome://extensions/
    ```
    
2. Включите:
    
    - **Режим разработчика (Developer Mode)** — переключатель в правом верхнем углу
        
3. (Если требуется)
    
    - Разрешите установку сторонних расширений (side-loaded extensions)
        
4. Установите расширение:
    
    - Перетащите `.crx` файл в окно расширений
        
    - Подтвердите установку
        

---

## 🚀 Использование

1. Откройте нужную таблицу Google Sheets
    
2. Нажмите на иконку расширения в панели браузера
    
3. Откроется новая вкладка:
    
    - Это клон текущей таблицы
        
    - Загружен в режиме `htmlview`
        
    - **Текст теперь можно свободно копировать**
        

---

## ⚠️ Особенности и ограничения

- Работает только с Google Sheets (`docs.google.com/spreadsheets`)
    
- Использует альтернативное представление (`htmlview`)
    
- Может отображать таблицу без некоторых интерактивных функций (редактирование, формулы и т.д.)
    
- Требует ручной установки (не из Chrome Web Store)
